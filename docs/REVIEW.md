# 首版代码审查

日期：2026-09-12。范围包括客户端状态、问卷规则、API 与模型契约、信源、依赖及发布内容。

## 已处理

| 问题 | 处理与验证 |
| --- | --- |
| 多页面覆盖原则或恢复已清除对话 | 存储版本核对、Web Locks 互斥；旧页面暂停保存。独立存储测试和真实双页面验证。 |
| 同页重复保存误报跨页冲突 | 同步防重入与保存中禁用；同一事件回合双击仅产生一次原则修订。 |
| 多键写入失败留下部分状态 | 回滚已写内容，保留原始错误；覆盖容量失败、中途清除失败及协调标识写入失败。若浏览器同时禁止回滚，继续阻止写入并显示错误。 |
| 合法中文原则超出原请求预算 | 累计流式读取上限 1,000,000 字节，严格 schema 不变；完整 20 条原则与 12 条历史通过测试。 |
| 停止等待未联动服务器请求 | 请求取消与 90 秒超时合并；构建后的 Workers 配置含 enable_request_signal。提供商是否停止计费不由本应用保证。 |
| 紧急回应被无关来源拒绝 | 结构校验后优先处理即时支持，清空哲学解释、来源与原则提议。 |
| 引用识别压过本人危险表达 | 仅排除局部引用与第三人称句子，保留同段第一人称危险判断；加入混合表达回归检查。规则仍只是补充兜底。 |
| 推荐并列时隐藏第四入口 | 明确说明并列，并提供第四个同分入口；不把展示顺序当作匹配强弱。 |
| RSC 运行依赖的已知拒绝服务问题 | React、React DOM、RSC 包升级至 19.2.8，确认框架实际引用项目安装包；类型、测试、检查及生产构建通过。 |

## 依赖剩余项

升级后 npm audit 仍报告 18 项：低危 1、中危 9、高危 8。高危包包括 brace-expansion、browserslist、image-size、js-yaml、undici、vite、ws，以及 image-size 上游 vinext 的重复计数。当前路径分别属于检查/构建工具、Vinext 本地图片处理、Miniflare 本地运行和开发服务器；本次未发现由生产用户输入触达这些问题的路径，未做穷尽性的可利用性验证。新增图片上传、YAML、用户自定义匹配或改变部署方式时需重新评估。

相关依据：[React 安全公告](https://github.com/react/react/security/advisories/GHSA-wx67-qw84-cm4g)、[Workers Request 取消行为](https://developers.cloudflare.com/workers/runtime-apis/request/)。
