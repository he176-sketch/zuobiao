# 后续 3—5 位真人试用说明与记录模板

状态：仅准备，尚未邀请任何人、未开展外部真人试用。当前候选版只能由负责人在本机验收；获得适合受邀参与者的受控入口后才安排试用，本轮未扩大权限。

## 给参与者的话

请从你自己最近的一件日常困惑开始。它可以很小，也可以还说不清。像平时一样使用，不需要先学哲学，也没有正确答案。

你可以不选基座、跳过问题、暂不写原则，或随时退出。想换一种方式时，可以自行探索。卡住了可以告诉观察者；我们想了解哪里让人困惑，不是在测试你。

体验约 10—15 分钟，也可以提前结束。结束后，我们想听听哪里有帮助、哪里没有。反馈完全自愿，可以只提供一句话、概述或不含原文的感受，不必交出完整对话；提交前请删去姓名、联系方式和其他私密信息。

对话默认留在当前页面；开启“在本机保留对话”才会保存到该设备。发送内容会经过现有 AI 服务商处理，本产品不新增后台对话收集。你可以导出、删除本机记录；不愿发送的内容无需输入。

## 观察者记录方式

让参与者先自行开始，不先示范怎样才能得到“好回答”。需要帮助时记录卡在哪一步、你具体解释了什么。使用代号，不记录真实身份；身份联系名单如有，应单独保管，不提交 Git。

以下类型必须分开标注：外部真实参与者 / 产品负责人验收 / 开发者操作 / AI 模拟。本轮没有外部真实参与者结果。

## 一人一份反馈模板（空白）

- 参与者代号：
- 日期、设备、浏览器（实体手机 / 桌面 / 浏览器移动模拟）：
- 本次类型：外部真实参与者 / 负责人验收 / 其他：
- 我愿意提供：仅概述 / 个别脱敏句子 / 自行挑选的脱敏片段 / 不提供内容。
- 从哪里开始？第一处困难是什么？是否需要旁人解释？解释了什么？
- 原问题的一句话概述（可空）：
- 哪一句真正回应了原问题？为什么？（可概述，不必贴原文）
- 哪一句没有回应、偏题、像套话或增加了负担？
- 有没有选择基座？若选择，请用自己的话说说它为什么这样判断；若没选择，可跳过。
- 有没有被迫答题、选基座或形成原则的感觉？
- 等待、失败、重试或再次进入时，有没有不理解或丢失内容？
- 面对另一件事，愿意继续使用吗？愿意 / 不愿意 / 说不清；原因：
- 其他想说的（可空）：

反馈保存到负责人指定的私人渠道。不要将本模板填写后的真实困惑、身份或私密片段提交到代码仓库。参与者可不提供全文；不以“形成了原则”或“用了全部功能”作为试用成功标准。
