# 坐标：首版产品范围

帮助用户认识、选择并逐渐修订自己的生活哲学。AI 依据用户认可的基座和个人原则，对生活中的困惑作出有理由、能落实到行动的回应，帮助减少不必要的内在冲突。心境平和是愿景，不是疗效或无痛承诺。

## 已实现的主线

1. 通过 12 个日常选择进入：工作、期待、关系、意义、后悔等；可跳过、返回修改或直接浏览。
2. 根据有效回答推荐 2–3 个起点，展示思想内核、具体回答依据、思考方向与取舍；仍由用户选择。
3. 探索四个基座，查看思想主张、生活应用、反对意见、历史范围和出处；可用同一困惑比较。
4. 以选定基座与当前确认的原则展开连续 AI 对话，可额外选择一个思考工具帮助拆解。
5. 查看回答的来源、哲学补充、工具方法与许可、个人原则快照。
6. 用户自行记录原则，或编辑 AI 提出的候选；确认后才生效。
7. 修改、删除和更换基座，保留修订记录；新的回答使用新版本，旧回答保留旧快照。

## 本版的边界

- 基座是经过选材的入口。理论组合会明确标为产品编排；不会把不同哲学家强行拼成无矛盾体系。
- 哲学用于价值判断与回应处境，不替代事实调查。不由人格、哲学或命运推断裁员、疾病等事件的原因。
- 对话以正常困惑为主；明确人身危险另行提供当下安全支持，不进行抽象生死辩论。
- 对话和原则只在浏览器端保留；没有服务器端客户案例库、账号档案库或跨设备同步。
- 原则默认本机保存；对话默认仅当前页面，用户主动开启后才持久化。可导出和清除。
- 初版以私人访问交付，尚未进行真实客户效果或商业需求验证。

## 内容与数据

`lib/foundations.json` 是经过网络核查的原创中文转述，四个基座、十二条原则、八条边界与九个信源。每条材料均含来源、章节、核查日期与内容使用说明。不收录受版权保护的现代著作或百科全文。

`lib/guide.ts` 定义对话约束。模型只可使用当前基座及本轮选择工具的来源 ID，普通回答仍须引用至少一个基座来源，服务器校验白名单；白名单检查不能独自证明每句话确实被来源支持，仍需要内容复核与持续评估。

`Profile`：当前基座、个人原则、修订号与修改记录。
`Message`：问题/回答、当时基座 ID、个人原则快照、材料与来源快照。
`Proposal`：未确认候选。模型没有写入浏览器存储的权限。

## 体验方向

安静的阅读与思考工作台。主色取自墨蓝与纸白，中文衬线标题配清晰正文。首次入口是一句困扰或生活情境，最多三步轻量探索；12 题问卷为可选深入路径。已有基座的用户直接输入正在经历的事情。思想范围和来源在侧栏展开。四个主要页面：聊一件事、探索基座、思考工具、我的原则。

首版不加入人格匹配分数、心理诊断、哲学家角色扮演、社交排行、打卡奖励或自动发布功能。

## 问卷如何工作

`lib/first-experience.ts` 分开保留处境与反应、求助方向、愿意探索的依据。透明编辑规则只读取明确的求助/依据选项，不从情绪或自由文本推断学派。不足以推荐时明确展示非匹配体验。候选预览为产品编写，不冒充实时 AI；点击后才保存基座并直接请求真实回应。未选基座时明确标示探索回应。

`lib/discovery.ts` 保留 12 个情境与轮换的四种可探索思路，增加非计分的消极/矛盾/说不清选项与自由补充。只有明确愿意尝试的思路参与推荐，至少四项才生成弱推荐；原选项 ID 不重新解释。它不是心理量表，没有人格标签或百分比，也不会自动确定基座或写入原则。深入回答与补充可带入原问题，明确标为本次探索，不是个人原则。

问答草稿在页面内存中，刷新会重开。成功对话默认仅当前页面，主动开启本机保存后可恢复。基座和确认的原则沿用现有本机修订机制；更换基座不删除旧回答，旧材料和原则快照仍可查看。本轮具体范围、验证和未验证内容见 [CONTROL.md](CONTROL.md)。

## 下一阶段的验证

用经过知情同意的新测试者验证：能否理解所选基座的前提与代价，回答是否具体且忠于基座，个人原则的修订是否影响后续回答，能否把形成的理解用于另一件事情。不能以“觉得很懂我”单独证明产品有效。

## 精选内容接入（0.2.0）

选编 Philoscopia 的四份非空思想档案，各取两条实践相关定位，补充中文解读、取舍与核查来源。补充内容仅归属于相应基座，不加入问卷评分，不把编者标签当测量结果。

从 Model Thinking 选出机会成本、沉没成本、可逆选择、后续影响、证据更新、小试验六种工具。资料在 `public/knowledge/` 可下载，原始选材、固定提交、校验摘要与许可保留于 `vendor/`，详见 `THIRD_PARTY_NOTICES.md`。不安装 MCP 服务或外部 Skill 运行时。

工具选择属于当前对话界面状态；切换或取消不改变 Profile，刷新后可重新选择。历史消息仍保留当时完整工具快照。首次选基座会保留此前预选的工具；更换已有基座、新对话会清空工具选择。
